## Featured Projects

End-to-end AI speech pipeline using OpenAI Whisper for transcription and emotion analysis. Applies transformer seq2seq models to generate fluent audio from dysfluent input, with a stammer severity scoring module for clinical fluency feedback.
`Whisper` `HuggingFace Transformers` `TTS` `Python`

### [Stock Price Prediction — Apple Inc.](https://github.com/Chandrashekar0123/Stocks-Prediction-AAPL)
Stacked LSTM network trained on 5+ years of AAPL data achieving **98% evaluation accuracy**. Deployed as a real-time Streamlit dashboard with live Yahoo Finance API integration.
`LSTM` `TensorFlow` `Keras` `Streamlit`

### [Age & Gender Prediction](https://github.com/Chandrashekar0123/Age-and-Gender-Prediction)

`VGG16` `Transfer Learning` `Flask` `OpenCV`
